# Session Note: April 23, 2026

## Scope
This session focused on the next step after validating the global references:

- return to **MaxHerding**
- use the **`NN1`** evaluator only
- keep the validated global baseline as the anchor
- introduce a new **RBF-with-ProbCover-cutoff** variant
- run new local-`K` sweeps against that cutoff-based global reference

The goal is to test a hybrid selector:

- keep MaxHerding's smooth RBF weights
- but zero out entries outside a ProbCover-style support threshold

## Main Idea
The professor's suggestion was to combine:

- the smooth MaxHerding kernel
- with a hard cutoff like ProbCover

Conceptually:

- ProbCover uses a hard threshold graph
- MaxHerding uses smooth RBF similarities
- the new variant keeps the RBF values only on edges that pass the ProbCover-style cutoff

So the new kernel is:

- smooth inside the support region
- exactly zero outside it

### Behavior
With:

- `--kernel_type rbf`
- `--rbf_cutoff_mode probcover`

the kernel is built as follows.

#### Global sigma
Keep an edge only if:

- `d(x_i, x_j) < delta`

If the pair is kept:

- use the usual RBF value

If not:

- set `K_ij = 0`

#### Local sigma
Keep an edge only if:

- `d(x_i, x_j)^2 / (sigma_i sigma_j) < delta^2`

If the pair is kept:

- use the usual local-sigma RBF value

If not:

- set `K_ij = 0`

This now matches the ProbCover-style thresholding idea properly, including the local-sigma case.

### Important Detail
This behavior is **opt-in**.

Default behavior remains unchanged unless:

- `--rbf_cutoff_mode probcover`

is passed explicitly.

## Why This Was Needed
We verified that the current repo already had partial support for zeroing RBF entries:

- dense RBF matrices could already be zeroed below a threshold
- sparse RBF matrices already had a keep-mask mechanism

But the exact ProbCover-style cutoff was not cleanly exposed as a MaxHerding option, and the local-sigma case needed a proper normalized-distance cutoff to match the ProbCover interpretation.

So we implemented it directly instead of trying to infer it indirectly from older sparse behavior.

## What We See
The broad pattern is:

- very small `K` values are clearly worse than the global cutoff baseline
- once `K` becomes larger, the local-sigma curves move back toward the global baseline
- at the stronger `K` values, performance is very close to the global reference

So yes, the main interpretation is:

- local `K` has only a limited effect here
- lower `K` hurts
- higher `K` becomes almost the same as global

The difference between datasets is:

- on **CIFAR-10**, there is still a small but fairly consistent gain at the best large `K`
- on **CIFAR-100**, the gains are very small and the local runs are mostly just matching the global baseline

## Interpretation
This cutoff experiment supports a similar conclusion to the earlier non-cutoff local-sigma story.

What it does **not** show:

- a strong benefit from genuine local adaptivity

What it does show:

- strongly local settings are harmful
- once `K` is large enough, local sigma becomes competitive again
- in that regime, it behaves almost like the global baseline

So the new cutoff did **not** create a qualitatively different picture.

It mostly reinforced:

- small `K` bad
- larger `K` near-global
- only modest gains, if any

## More Specific Read

### CIFAR-10
The cutoff variant did produce a repeatable best region:

- `K=3500` was best for all three seeds

So there is a weak positive signal there.

But even here, the improvement is still small enough that the overall story remains:

- local sigma is only competitive once it becomes quite smooth

### CIFAR-100
The best region was:

- `K=960-1440`

But the improvements over global were tiny.

So for CIFAR-100, the practical conclusion is even stronger:

- local sigma with cutoff behaves almost the same as global sigma once `K` is large enough

## Updated Conclusion
The current evidence from the cutoff experiments is:

1. Adding a ProbCover-style cutoff to MaxHerding does not unlock a strong local-sigma advantage.
2. Small `K` values remain clearly worse.
3. Larger `K` values mostly recover the global baseline.
4. CIFAR-10 shows a small consistent gain at the best large `K`.
5. CIFAR-100 is almost entirely a “match global” story, not a “beat global” story.

So the main takeaway is still:

- if local sigma helps at all, it helps in a regime where it is already behaving very similarly to global sigma

## Likely Next Question
Given these results, the next scientific question is probably not:

- “what is the exact best local `K`?”

but rather:

- “is there any real evidence left that localization itself is the useful ingredient?”

At this point, the answer still looks close to:

- probably not
