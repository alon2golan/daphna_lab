## What We Expected
We expected:

- very small `K` to be too local and hurt
- larger `K` to smooth local sigma and make it more stable
- local sigma to maybe improve once `K` is large enough
- if local sigma truly helps because of localization, we would hope to see gains in a meaningfully local regime, not only when it becomes nearly global-like

## What Surprised Us

### 1. CIFAR-10 SGD-Linear Was Very Unstable
The old SGD-based linear separator on CIFAR-10 looked suspicious:

- the curves jumped up and down a lot
- they were far from monotone

We checked the code path and found:

- it was **not** the old “uses only the current episode” bug
- it **does** train on the accumulated `lSet`
- the instability likely comes from the evaluation protocol itself:
  - linear head trained with generic SGD
  - standard CIFAR optimizer settings
  - retraining from scratch every AL round
  - tiny labeled sets

### 2. Bigger `K` Is Not Always Better
Performance usually improved from tiny `K` to moderate-large `K`, then flattened or declined.

So the story is not:

- “bigger K is always better”

It is closer to:

- “there is an optimal smoothing range”

## What the Sigma Stats Show
The sigma statistics were one of the most useful outputs of the session.

As `K` increases:

- mean sigma increases
- median sigma increases
- relative variability drops sharply
- `cv` drops a lot
- `iqr` drops a lot

This means:

- small `K` gives noisy, strongly local sigmas
- large `K` gives smooth sigmas that behave much more like a global scale

That matches the intuition:

- small `K` = strongly local, unstable
- large `K` = smoother, more global-like

## Main Interpretation
This became the main conclusion of the session:

- only relatively large `K` values are competitive with global sigma
- but at those large `K`s, the sigma distribution is already very smooth
- so the good local-sigma regime may actually be a **near-global** regime

That means the current results do **not** strongly support the claim:

- “localization itself helps”

A more careful claim is:

- strong locality hurts
- a smoothed self-tuning version can match or slightly beat global sigma
- any gain may come from mild adaptive scaling, not from truly local behavior

So the current evidence supports:

- “local sigma is not useless”

more than:

- “local sigma helps because it is local”

## What Looks Most Trustworthy
Most trustworthy:

- `NN1`
- logistic regression

Least trustworthy:

- CIFAR-10 SGD-linear separator

Why:

- `NN1` is simple and mostly deterministic once the labeled set is fixed
- logistic regression is a stable linear classifier on frozen features
- SGD-linear on tiny feature sets is much noisier

So the cleanest comparisons right now are:

- global vs local under `NN1`
- global vs local under logistic regression

## Practical Conclusions
1. Small `K` is consistently bad.
2. Local sigma only becomes competitive when `K` is large enough to strongly smooth the sigma field.
3. The best `K` seems to be in a moderate-large range, not necessarily the largest possible value.
4. The current evidence does not justify a strong claim that “locality helps.”
5. Logistic regression is a better linear-eval protocol than the old SGD-based linear separator in this setting.

## Points To Think About Before the Meeting
- Are we trying to show that local sigma is useful in general, or only that a smoothed self-tuning variant can sometimes slightly improve over global sigma?
- If the best local-sigma regime is already close to global sigma, is local sigma really the key effect?
- Should we describe the method as “mild adaptive scaling” rather than “local self-tuning”?
- Do we want to search for a heuristic for `K`, or first establish whether the advantage over global sigma is robust across more seeds?
- Should the main evaluation protocol moving forward be logistic regression instead of SGD-linear?

## Logistic Regression Reminder
Logistic regression is a linear classifier on the feature vectors.

For a feature vector `z`, it computes one score per class:

\[
s_c = w_c^T z + b_c
\]

Then it converts scores into class probabilities with a softmax and predicts the class with the highest probability.

Compared with the other evaluators:

- `NN1`: nearest labeled feature
- `from_features`: linear layer trained by SGD
- `logistic_from_features`: linear classifier fit directly by scikit-learn logistic regression

It still uses the same frozen feature space. It does **not** use the `K` matrix.

## Short Version
We ran organized low-budget MaxHerding sweeps comparing global sigma to local sigma across many `K` values, and evaluated them with `NN1`, SGD linear, and logistic regression on frozen features. Small `K` consistently hurt. As `K` increased, local sigma improved and sometimes slightly beat global sigma, but the sigma stats show that in this regime the sigmas become much smoother and more global-like. So the current evidence does not strongly show that localization itself helps; rather, a mildly adaptive near-global scaling may help a bit. The old SGD linear evaluation on CIFAR-10 looked unstable, so we added logistic regression, which gave a much cleaner and more trustworthy picture.
