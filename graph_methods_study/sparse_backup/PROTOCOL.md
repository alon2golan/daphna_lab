# Confirmatory backup coverage pilot

The previous five-seed pilot of backup coverage used seeds 17, 29, 41, 53, and 67. This confirmation freezes five fresh warm-start and noise seeds, 30 through 34, before scoring. The same seeded reverse-13NN binary coverage produces the common warm batch of 100 within each seed. Subsequent batches of 100 maximize exact weighted RBF coverage on the same sparse BYOL support graph. The comparison changes only the coefficient on the second strongest distinct anchor, from 0 to 0.5. Fixed checkpoints have 400, 800, 1,200, 1,600, and 2,000 unique noisy acquisitions. Each seed and condition shares the same corruption realization across both arms. The arms never use the corruption type or any labels in acquisition.

The primary replication metric is the mean paired test accuracy difference across the 1,600- and 2,000-label checkpoints in symmetric 50% noise with three-hop graph votes. Compute the mean across the two budgets within each seed before aggregating the five seeds. The prespecified transfer endpoint applies six-hop votes to the same ordered queries and annotations. Both graph heads evaluate 10,000 held-out test images using edges into the 45,000-image train pool. Compare symmetric and superclass-cycle asymmetric noise at 30%, 40%, and 50%, and include clean and CIFAR-100N. Cosine 1NN is a secondary metric. The heads do not train an MLP.

The pilot uses the identical 45,000 neighbor lists and 10,000 held-out neighbor lists exported for the previous active audit. The six-hop path counter uses signed 32-bit integer arithmetic. A toy matrix multiplication check verifies both walk depths. A separate exact greedy check verifies sparse incremental scoring against exhaustive candidate rescoring. Source, shared helper, and geometry checksums are saved with every result.
