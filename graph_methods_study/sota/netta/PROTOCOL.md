# Netta noisy active-learning baselines on CIFAR-100 BYOL

Compare ordinary ProbCover, NPC, weighted NPC and MaxHerding+NAS at 400, 800, 1,200, 1,600 and 2,000 noisy annotations. An existing exact MaxHerding order is included as a shared-head reference. Every trajectory starts with the same first 100 Gaussian MaxHerding queries, then acquires unique samples in batches of 100 from the same 45,000 frozen BYOL rows. The 10,000 independent test images are excluded from acquisition. Conditions are the seed-0 archived clean, symmetric and superclass-cycle asymmetric 20/30/50%, and CIFAR-100N. The main metrics use all acquired annotations and the same inductive three-hop and six-hop graph voting and cosine 1NN. The scorecard also evaluates those same heads using acquired IDs that pass LowBudgetAUM so the training filter can be compared independently.

NPC and weighted NPC both use the 0.50 frozen BYOL radius already used by the lab. NPC removes existing predicted-clean coverage. Weighted NPC also multiplies demand in predicted-noisy neighborhoods by the estimated clean fraction, except where predicted-clean coverage removes those targets. MaxHerding+NAS masks predicted-noisy anchors out of the initial coverage but never allows any previously selected item to be acquired again. New selections cover their targets during the current batch. The three acquisition rules follow the fixed-radius/default-dropout decision logic in the [official Netta release](https://github.com/nettashafir/active_learning_with_label_noise/tree/733651bb0943a96392895103eb2ffc4e99a7c7d1/deep-al/pycls/al). The comparison uses seeded CPU tie-breaking for radius variants and archived row-order ties for Gaussian coverage.

All NAS arms use the same October-pinned lab adaptation of LowBudgetAUM. It is a 40-epoch linear detector on unit-normalized frozen observations with 80th-percentile thresholding on ceil(B/100) fake-label examples sampled from the currently unacquired pool. It uses one training repeat with batch size 64, SGD learning rate .1, weight decay 1e-4, momentum .9 and Nesterov. The comparison fixes query-side noise dropout to off, matching the official code's default. It differs from the original paper's SimCLR features, asymmetric channel, radius scheduling and supervised evaluation heads.

The smoke job checks incremental radius scoring against full enumeration, validates dense coverage against full enumeration on a toy graph, and reproduces the archived Gaussian second batch when no prior anchors are flagged. Each result saves the ordered acquisition indices, noisy annotations, detector masks, held-out test counts and source/geometry identities. The geometry and prior results remain read-only.
