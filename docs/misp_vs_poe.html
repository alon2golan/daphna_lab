Posterior update models

BAYES_MISP vs PoE

How one unlabeled point’s class posterior updates as labeled samples arrive nearby.

All values computed with: C = 10 classes uniform prior π(k) = 1/C = 0.1 MISP prior pseudo-count α = 0.1 per class u = the unlabeled point tracked ℓ = an arriving labeled sample; c = ỹℓ its observed label kernel Kuℓ ∈ [0,1]

BAYES_MISP — additive counts

evidence adds

State & init
C[u,k] = α  for every class k
Update per labeled sample ℓ (observed label c)
C[u,c]  +=  Kuℓ
Posterior
P(yu = k) = C[u,k] / Σj C[u,j]
  • C[u,k] pseudo-count: kernel mass of class-k votes near u
  • α prior pseudo-count per class; here α = π(k) = 0.1, so the initial posterior is the prior. A non-uniform prior enters as non-equal initial counts αk ∝ π(k)
  • Kuℓ vote weight — evidence adds linearly
  • — no annotator term: the observed label is counted as truth

PoE — product of experts

evidence multiplies

State & init
C[u,k] = log π(k)
Step A — annotator likelihood
Lℓ(k) = M[k, c]
Step B — kernel gating
qℓ(u,k) = Kuℓ·Lℓ(k) + (1−Kuℓ)·(1/C)
Step C — fuse all neighbors, posterior
C[u,·] += log qℓ(u,·)  ⇒  P(yu) = softmax(C[u,·])
  • M[k,j] annotator confusion matrix, P(observed j | true k); symmetric with accuracy r: diagonal r, off-diagonal (1−r)/(C−1)
  • qℓ(u,k) the message ℓ sends about u: with probability Kuℓ they share a true label, so Lℓ applies; with probability 1−Kuℓ they are unrelated and the message is the uniform 1/C — constant in k, so a far neighbor is evidence-free

Section 3

Noisy annotator — 50% noise

Section-1 scenarios again (in-ball, K = 1), but the annotator is 50% symmetric-noisy: r = 0.5, so M has 0.5 on the diagonal and (1−0.5)/9 = 0.0556 off it. PoE decodes this in Step A: Lℓ(c) = 0.5, Lℓ(other) = 0.0556 — each label is now a likelihood ratio of 9, not a veto. MISP has no annotator term, so its update and all its numbers are identical to Section 1.

Section 5

The tempered term β·w

Same arrivals as Section 4 (close A at K = 0.9, far crowd labeled B). PoE’s Step C gains the tempered term:

C[u,·] += β·wuℓ·log qℓ(u,·) ,   wuℓ = Kuℓ ,  β = 1

The kernel now enters twice — inside the message qℓ and again as the weight — so a far point’s log-evidence toward B shrinks from log(0.109/0.099) = 0.096 to 0.01 × 0.096 ≈ 0.001, while the close label keeps 0.9 × log(0.91/0.01) = 4.06: the flip moves from n ≈ 47 to n ≈ 4200. Sections 1 and 3 would be unchanged (K = 1 ⇒ w = 1); in Section 2 each message is raised to the power 0.9 (one label: 0.9100 → 0.8656).
